## 📚 Installation de la base de données MySQL pour ce projet

Voici les étapes à suivre pour installer et configurer la base de données MySQL nécessaire à ce projet PHP.


### ✅ Prérequis

- **Serveur MySQL** (par exemple : MySQL 5.7+ ou MariaDB)
- **phpMyAdmin** (facultatif, pour gérer la base de données via une interface graphique)
- **Un environnement de développement local** comme XAMPP, WAMP ou MAMP (inclut Apache, PHP, et MySQL)
- Le fichier SQL fourni avec le projet : `reb_db.sql` (ou autre nom si différent)

### 🛠️ Étapes d'installation

1. **Lancer le serveur MySQL**  
   Si tu utilises XAMPP, WAMP ou MAMP, démarre les services **Apache** et **MySQL**.

2. **Créer la base de données**

   #### Avec phpMyAdmin :
   - Accède à [http://localhost/phpmyadmin](http://localhost/phpmyadmin)
   - Clique sur **"Nouvelle base"**
   - Donne le nom 'lebonplan_db'à la base
